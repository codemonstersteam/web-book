# WireGuard vpn за 15 минут
Привет, netrunner.
Сеть это твой мир. Это наша общая память в киберпространстве.
Я перерыл десяток статей, чтобы найти простой пример, который работает с минимальным количеством строк.
Чтобы тестировать софт и безопасно исследовать пустош безопасность лишней не будет.

[WireGuard®](https://www.wireguard.com/) — это чрезвычайно простой, но быстрый и современный VPN, использующий современную криптографию. Он стремится быть быстрее, проще, компактнее и полезнее IPsec, избегая при этом страданий. WireGuard стремится быть шустрее, чем OpenVPN. WireGuard разработан как универсальный VPN для работы на встроенных интерфейсах и суперкомпьютерах, подходящий для самых разных обстоятельств. Первоначально выпущенный для ядра Linux, теперь он является кроссплатформенным (Windows, macOS, BSD, iOS, Android) и широко развертываемым.

## Установка WireGuard

WireGuard доступен напрямую из официальных репозиториев на Ubuntu 24.04. 
Однако перед установкой WireGuard убедись, что система обновлена.
````bash
sudo apt-get update && sudo apt-get upgrade -y
````

Теперь можно установить сам WireGuard и все его зависимости.
````bash
sudo apt-get установить wireguard
````
Повтори шаги установки на каждом клиенте, который ты хочешь подключить к серверу WireGuard.

WireGuard имеет софт для большинства операционных систем, 
поэтому ты можешь легко подключить свои устройства Windows, Linux или macOS к устройствам Android или iOS. 
Доступные пакеты находятся на странице [загрузки](https://www.wireguard.com/install/).

После установки WireGuard продолжите настройку сервера, следуя инструкциям ниже.

## IP forwarding
Далее, чтобы гонять трафик через сервер WireGuard, тебе нужно включить пересылку пакетов. 
Это делается только на сервере WireGuard и не является обязательным для клиентов.


Открой файл системных переменных для редактирования.  
````bash
sudo nano /etc/sysctl.conf
````
Затем раскомментируйте следующую строку, удалив символ # в начале строки.  

````bash
net.ipv4.ip_forward=1
````
После этого сохрани файл и выйди из редактора.  

Затем примени новую опцию с помощью команды ниже.  

````bash
судо sysctl -p
````

````bash
net.ipv4.ip_forward=1
````

Если при перезагрузке системных переменных ты видишь опцию, как указано выше, значит опция была успешно включена.

## Настройка файрволла
Тебе следует настроить брандмауэр, 
чтобы блокировать нежелательные соединения и поддерживать безопасность сервера. 
Ты можешь сделать это, установив программный брандмауэр на облачном сервере.

Используя команду ниже, ты можешь установить UFW — простой брандмауэр для серверов Ubuntu.  

````bash
sudo apt install ufw
````

Затем добавь следующие правила, чтобы разрешить соединения SSH и WireGuard.  
````bash
sudo ufw allow ssh
sudo ufw allow 51820/udp
````

Включи брандмауэр с помощью следующей команды.
````bash
sudo ufw enable
````
Подтверди команду при появлении соответствующего запроса.
````bash
Command may disrupt existing ssh connections. Proceed with operation (y|n)? y
````

После этого ты можешь проверить активные правила брандмауэра с помощью команды ниже.
````bash
sudo ufw status
````

## Генерация закрытых и открытых ключей 

WireGuard работает, шифруя соединение с помощью пары криптографических ключей. Пара ключей используется путем обмена открытым ключом с другой стороной, которая затем может зашифровать свое сообщение так, чтобы его можно было расшифровать только соответствующим закрытым ключом. Чтобы сделать связь безопасной в обоих направлениях, у каждой стороны должны быть закрытые и открытые ключи, поскольку каждая пара обеспечивает только односторонний обмен сообщениями.  

Для использования в WireGuard сервер и каждый клиент должны сгенерировать свою пару ключей, а затем обменяться открытыми ключами.  

Чтобы начать генерацию ключей для сервера, перейди в каталог WireGuard.  

````bash
cd /etc/wireguard
````

Далее установи разрешения для каталога с помощью следующей команды. 
Для этого необходимо войти в систему с учетной записью root. (sudo su)

````bash
umask 077
````

Установив необходимые разрешения, сгенерируй новую пару ключей с помощью команды ниже.
````bash
wg genkey | tee privatekey | wg pubkey > publickey
````
Результат работы ниже - два файла.
````bash
 sudo ls -la /etc/wireguard/
````

````bash
-rw-------   1 root root   45 Apr 26 08:23 privatekey
-rw-------   1 root root   45 Apr 26 08:23 publickey
````
Повтори эти шаги для каждого клиента, которого хочешь подключить к серверу WireGuard.

Помни, что никогда не следует передавать свой закрытый ключ кому-либо. Даже мне.

## Сгенерируй конфигурацию сервера
Затем мы готовы начать настройку сервера WireGuard. Файлы конфигурации обычно хранятся в папке /etc/wireguard . Создайте в этой папке новый файл конфигурации с именем wg0.conf .

```shell
sudo nano /etc/wireguard/wg0.conf
```

Приведенная ниже конфигурация позволит вашему серверу WireGuard принимать соединения с портом 51820 и разрешать подключение клиентов с открытым ключом, соответствующим закрытому ключу, который мы создали выше.

Добавьте следующие директивы в файл конфигурации.
```shell
[Interface]
PrivateKey = <contents-of-server-privatekey>
Address = 10.0.0.1/24
PostUp = iptables -A FORWARD -i wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o **eth0** -j MASQUERADE
PostDown = iptables -D FORWARD -i wg0 -j ACCEPT; iptables -t nat -D POSTROUTING -o **eth0** -j MASQUERADE
ListenPort = 51820

[Peer]
PublicKey = <contents-of-client-publickey>
AllowedIPs = 10.0.0.2/32
```
Если имя вашего сетевого интерфейса по умолчанию отличается, возможно, вам придется проверить его и заменить **eth0** на него в конфигурации выше.

```shell
ip route list default
```
Обратите внимание, что файл конфигурации должен включать в себя фактические ключи, строку букв, цифр и символов. Вы можете прочитать файлы ключей с помощью следующих команд.

```shell
sudo cat /etc/wireguard/publickey
sudo cat /etc/wireguard/privatekey
```
Затем сохраните файл и выйдите из редактора.


## Запуск WireGuard и включение его при загрузке

После настройки мы готовы запустить сервер. WireGuard имеет удобную оболочку wg-quick , которую можно использовать для запуска новых интерфейсов без необходимости вникать в детали настройки. Вы можете использовать ее для запуска своей конфигурации с помощью следующей команды.  
```shell
wg-quick up wg0
```
После успешного запуска интерфейса вы должны увидеть вывод, подобный показанному ниже.  
```shell
[#] ip link add wg0 type wireguard
[#] wg setconf wg0 /dev/fd/63
[#] ip -4 address add 10.0.0.1/24 dev wg0
[#] ip link set mtu 1420 up dev wg0
[#] iptables -A FORWARD -i wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
```
Ваш сервер WireGuard запущен. Вы можете проверить свою конфигурацию с помощью следующей команды.  

```shell
wg show
```

```shell
interface: wg0
  public key: pcDxSxSZp5x87cNoRJaHdAOzxrxDfDUn7pGmrY/AmzI=
  private key: (hidden)
  listening port: 51820

peer: gCQKfJL8Xff2MNmvceVQ0nQAmLsSM0tXClhvVNzSil4=
  allowed ips: 10.0.0.2/32
```

Чтобы включить автоматический запуск WireGuard при загрузке системы, также включите службу systemd.
```shell
systemctl enable wg-quick@wg0
```
## Настройка клиента

После того, как ваш сервер WireGuard запущен и работает, вам необходимо настроить клиентское устройство. Они предлагают программное обеспечение для большинства операционных систем, чтобы легко подключать ваши устройства Windows, Linux или macOS и Android или iOS. Вы можете найти доступные пакеты на их странице загрузки .

Создайте новый файл конфигурации в каталоге /etc/wireguard на клиентском компьютере.

```shell
sudo nano /etc/wireguard/wg0.conf
```

Затем добавьте в этот файл следующее. Не забудьте установить клиентский закрытый ключ и серверный открытый ключ в соответствующие места и включить публичный IP-адрес вашего сервера WireGuard.
```shell
[Interface]
Address = 10.0.0.2/32
PrivateKey = <contents-of-client-privatekey>
DNS = 1.1.1.1

[Peer]
PublicKey = <contents-of-server-publickey>
Endpoint = <server-public-ip>:51820
AllowedIPs = 0.0.0.0/0, ::/0
```

Обратите внимание, что установка AllowedIPs на 0.0.0.0/0, ::/0 будет пересылать весь трафик через VPN-подключение WireGuard. Если вы хотите использовать WireGuard только для определенных пунктов назначения, укажите диапазоны их IP-адресов в списке, разделенном запятой.

После установки ключей и адреса сервера сохраните файл и выйдите из редактора.

Запустите соединение с помощью команды ниже.

```shell
sudo wg-quick up wg0
```
Вы также можете использовать системную команду для запуска WireGuard как службы.  
```shell
sudo systemctl start wg-quick@wg0
```
Затем, когда вы захотите отключиться, используйте одну из следующих команд в зависимости от того, какой метод вы использовали для его запуска.  
```shell
sudo wg-quick down wg0
sudo systemctl stop wg-quick@wg0
```

Затем WireGuard отключится от сервера и удалит соответствующие сетевые настройки.

## Добавление клиентов
Вы можете добавить больше клиентов на свой сервер, если хотите использовать WireGuard VPN на других устройствах. Добавление клиентов простое.

Сначала установите WireGuard на новые клиентские устройства, как и раньше, и создайте новую пару ключей.

Далее остановите сервер, чтобы иметь возможность редактировать конфигурацию.  

```shell
sudo wg-quick down wg0
sudo systemctl stop wg-quick@wg0
```
Затем отредактируйте файл wg0.conf на вашем сервере WireGuard.  

```shell
sudo nano /etc/wireguard/wg0.conf
```
Добавьте следующую запись в конец файла, чтобы включить открытый ключ вашего второго клиента и задать IP-адрес.    

```shell
[Peer]
PublicKey = <content-of-client2-publickey>
AllowedIPs = 10.0.0.3/32
```

После этого сохраните файл и выйдите из редактора.

Затем перезапустите службу, чтобы обновить конфигурацию.  

```shell
sudo systemctl start wg-quick@wg0
```  

Готово! Теперь вы можете подключиться к новому клиенту, как вы делали это раньше.
